# 🏆 Sports Card League Simulator

A Python-based sports card comparison and league simulation game featuring football, basketball, and volleyball players.

The project allows users to compete against a computer opponent using sports cards. Each card represents an athlete with sport-specific attributes and special abilities. Players compete by selecting attributes and comparing their values to determine the winner of each round.

The application combines object-oriented programming, strategic decision-making, card management, and an interactive graphical user interface.

## ✨ Features

### 🎮 Game Mechanics
- Player vs. Computer gameplay
- Round-based card comparison system
- Automatic winner determination
- Score tracking throughout the game
- Game state management
- Automatic game completion when playable cards run out
